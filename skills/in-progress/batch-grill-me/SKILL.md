description: 一轮一轮地提问整片前沿问题的不懈访谈。
disable-model-invocation: true
---

不懈地访谈用户，直到达成共识。将这件事映射为一棵**设计树**（design tree）：每个决策分叉出依附其上的下游决策。

按**轮次**推进这棵树。**前沿**（frontier）是所有前置条件已经确定的决策——那些你*现在*就能提问、而无需猜测尚未听到的答案的问题。每轮一次性提出整片前沿：给每个问题编号并附上你的推荐答案。然后等待用户的回答再进入下一轮。

用户每一轮的回答都会重塑这棵树——已敲定的决策把前沿向外推，解锁了依赖它们的问题。重新计算前沿再开启下一轮。一个答案依赖本轮中另一个仍未敲定问题的问题，属于*更晚的*轮次，不属于这一轮。

查找**事实**是你的活，绝不是用户的。当前沿问题需要环境（文件系统、工具等）中的某个事实时，派一个子 agent 去找——不要让用户提供任何你自己能查到的东西。不要为它阻塞：一个正在进行的探查就是一个未敲定的前置条件，只有其下游问题需要等子 agent 回报——其余前沿现在就问。**决策**是用户的——把每一个决策摆给他们，然后等。

会话在前沿为空时结束：设计树的每个分支都已遍历，没有任何东西被默默假设。在用户确认你们已达成共识之前，不要据此行动。
