---
name: research
description: 针对高可信度的一手来源调查问题，并将发现捕获为仓库中的 Markdown 文件。当用户想要研究某个主题、收集文档或 API 事实，或将阅读跑腿工作委托给后台 agent 时使用。
---

启动一个**后台 agent** 来进行研究，这样你在它阅读时继续工作。

它的工作：

1. 针对**一手来源**（primary sources）调查问题 —— 官方文档、源代码、规格、第一方 API —— 而不是它们的二手转述。将每个声明追溯到拥有它的来源。
2. 将发现写入单个 Markdown 文件，引用每个声明的来源。
3. 将其保存在仓库已有此类笔记的地方；匹配现有约定，如果没有，放在合理的地方并说明在哪里。
