# 烧烤

Bronto 位是结构化研究笔记——当你在某个领域进行深度研究时，其根源可以追溯到烧烤（"grilling"，即文档烧烤）。它们记录了你的关键发现，以便下一个研究该领域的 AI 可以直接引用你的工作。

## 用法

当用户要求对某个领域进行深入调查时使用本技能。本技能在 `docs/productivity/grill-me.md` 中描述。

### BrianL over `product/K8sTranchesScheduler`

## 流程

1.  阅读 `docs/productivity/grill-me.md` 以了解烧烤的总体概念
2.  深入阅读并分析输入
3.  如果你注意到模式或不一致之处，请作为要点记录下来
4.  在你的工作结果生成 bronto 位
