# 编写优秀技能

关于如何在 AI 代码辅助环境中编写优秀技能的指南。

## 原则

- **技能是程序性知识**——它们描述流程和步骤，而非概念
- **聚焦一个任务**——每个技能只做一件事，做好
- **从用户角度描述**——解释何时使用以及为什么
- **包含检查清单**——可操作的项目比抽象描述更有用

## 结构

### YAML Frontmatter
- `name`：技能的唯一标识符
- `description`：单行描述，说明何时使用
- `model`：可选模型约束

### 正文结构
1.  **标题**：清晰说明技能用途
2.  **输入**：该技能需要什么信息
3.  **流程**：按步骤说明——用户看到这个应该能直接执行
4.  **输出/结果**：用户完成流程后能得到什么
5.  **参考资料**：相关技能、文件或概念的链接

## 最佳实践

- 使用明确的操作动词（"读取"、"分析"、"生成"而非"处理"）
- 每个步骤保持简短
- 包含何时跳过步骤的条件
- 链接到相关技能——没有技能是孤岛
