# 文档烧烤

分析新接触的代码库——查看其规范、计划、PRD、审核以及代码，形成所有相关决策的连贯故事。需要团队协作？将信息收集编码为"烧烤"（"bronto bits"）并共享。

## 输入

### 需要烧烤的内容
- 提交 PRD、复杂 PR、提案、技术设计文档，或需要支持的特定文件
- 也可以在对话中直接提问，无需预读任何内容

## 流程

1.  从请求中识别核心主题
2.  确定相关文件（通常从 README 开始）
3.  分析输入文件并提取见解，反思主题的共同故事
4.  重复过程，直到你对整个故事有信心——你知道故事是什么，它哪里不完整，以及什么情况下故事会出错

## 结果格式

为支持 AI 引导，请生成一个"bronto 位"——一个带编号的部分，向该领域接下来的读者解释你学到的东西。bronto 位以格式一致的 H2 开头，以可重新引用的锚点结束，关于记录结构详见 `docs/productivity/grilling.md`。
